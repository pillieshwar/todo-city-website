A **mode** shows only the projects you pick. In **Work**, Today, Calendar, the menu bar and, if you like, notifications show only your work projects. Everything else waits, a click away.

![The mode menu open at the top of the sidebar: Work, Personal, Study and Everything, with their shortcuts](/docs/img/mode-menu.webp "Switch modes at the top of the sidebar.")

## Switch modes

Click the switch at the top of the sidebar and pick a mode, or use the keys:

| Keys | Mode |
| --- | --- |
| <kbd>⌃⌥1</kbd>, <kbd>⌃⌥2</kbd>… | Your modes, in order |
| <kbd>⌃⌥0</kbd> | Everything |

In a mode, a line under the list tells you how many tasks are waiting outside it, with **Show** to see them. A project's own page and [search](/docs/search) always show every task.

## Work and Personal

TodoCity starts with two modes:

- **Work** shows the **Office** project and tasks with no project. New tasks with no project go to Office.
- **Personal** shows every project except Office, including projects you make later. New tasks with no project go to **Home**.

Change both in **Settings → Modes**.

## Make your own

![Settings → Modes with Work selected: the projects it shows, its calendars, and the mode this Mac is in](/docs/img/settings-modes.webp "Settings → Modes.")

:::steps
1. **Open Settings → Modes** and click **+ New mode**.
2. **Name it** and give it an icon (an emoji).
3. **Tick the projects** it shows, and whether it shows **Tasks with no project**.
4. **Choose the rest**, below.
:::

| Setting | What it does |
| --- | --- |
| **Show new projects here too** | Projects you make later appear in this mode by themselves |
| **Notifications only for these projects** | While you're in this mode, reminders for other projects wait until you switch |
| **New tasks go to** | The project that new tasks with no project join while this mode is on |
| **Calendars in Work** (named after the mode) | Which calendars show while the mode is on |

To remove a mode, click **Delete mode**.

## Each Mac keeps its own mode

Modes only change what's shown. Your tasks stay the same everywhere, and [sync between your Macs](/docs/sync-between-macs) keeps them in step. Each Mac remembers its own mode: say, Work on the work laptop and Personal at home. Set it under **On this Mac → Mode this Mac is in** in **Settings → Modes**.
